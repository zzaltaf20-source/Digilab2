# Available Flip-Flop Experiments

5 Fully Simulated Modules
EXP-01 Clocked / NOR-NAND

SR Flip-Flop (Set-Reset)

Fundamental bistable multivibrator. Explore Set, Reset, Memory Hold, and the Forbidden / Invalid condition (S=1, R=1).

EXP-02 Edge-Triggered 74LS76

JK Flip-Flop (Universal)

Overcomes the SR invalid state by implementing Toggle mode when J=1, K=1. Includes active-LOW Asynchronous PRE & CLR terminals.

EXP-03 74LS74 Data Latch

D Flip-Flop (Data / Delay)

Transfers input data D straight to output Q upon active clock edge. Crucial building block for shift registers and CPU buffers.

EXP-04 Frequency Divider

T Flip-Flop (Toggle)

Toggles output state on each active clock pulse when T=1. Forms ripple binary counters and divide-by-2 digital clocks.

EXP-05 Pulse-Triggered Dual Stage

Master-Slave JK Flip-Flop

Completely eliminates race-around conditions in level-triggered JK flip-flops. Master stage samples during CLK=1; Slave stage transfers to output Q during CLK 1-to-0 transition.
